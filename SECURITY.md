# Política de segurança

## Como reportar uma vulnerabilidade

Não abra uma issue pública. Envie os detalhes (passos para reproduzir, impacto, versão) para **seguranca@coffeeja.com.br** *(endereço a confirmar antes do lançamento)* ou use o recurso **"Report a vulnerability"** da aba *Security* do repositório no GitHub.

Compromissos: confirmar o recebimento em até 3 dias úteis e informar o andamento da correção. Pedimos que dados de usuários reais não sejam acessados, alterados ou divulgados durante os testes.

## Versões suportadas

Apenas a branch `main`.
